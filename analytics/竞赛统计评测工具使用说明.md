# 竞赛统计评测工具

这套工具的目标不是单纯生成“好看的图”，而是把项目现有评测数据转换为可复现、可审计、适合答辩的统计证据。

## 新增能力

- RAG：Recall@K、95% Wilson 区间、边际命中收益、Recall-K 曲线面积、帕累托前沿。
- Agent 路由：逐类 Precision/Recall/F1、Macro/Micro/Weighted F1、Balanced Accuracy、Cohen's Kappa、多分类 MCC。
- 延迟：Mean、P50/P90/P95、标准差、变异系数、IQR、固定种子的 Bootstrap 置信区间。
- 模式对比：Cliff's Delta 效应量、双侧 Mann–Whitney U 精确置换检验。
- 可靠性：请求成功率的 Wilson 区间，避免把小样本的 8/8 直接表述成“100% 可靠”。
- 实验设计：按目标置信区间宽度给出下一轮黄金集的样本量规划。
- 可追溯性：输出包含评测日期、输入数据 SHA-256 指纹、Bootstrap 次数与随机种子。

## 使用方式

在项目根目录运行：

```powershell
python -m analytics.generate_competition_report
```

默认输入：

```text
analytics/results/paper_metrics_2026-07-29.json
```

默认输出：

```text
docs/competition-analytics/
├── competition_metrics.json
├── competition_report.md
├── 01_RAG不确定性与边际收益.png/.svg
├── 02_Agent路由诊断.png/.svg
├── 03_延迟分布与效应量.png/.svg
└── 04_核心指标置信区间.png/.svg
```

也可以指定新一轮快照和输出位置：

```powershell
python -m analytics.generate_competition_report `
  --input analytics/results/competition_metrics_latest.json `
  --output-dir docs/competition-analytics/latest
```

仅计算统计指标和 Markdown 报告、不生成图片：

```powershell
python -m analytics.generate_competition_report --no-charts
```

## 输入数据原则

所有结果必须来自冻结快照。快照中的聚合数据只能支持其实际包含的指标：当前文件没有逐查询排序列表，因此工具不会伪造 MRR、nDCG 或逐样本 Bootstrap。后续若要加入这些指标，应在在线评测阶段保存每个问题的候选文档顺序、相关性等级和耗时，而不是从 Recall 聚合值反推。

## 答辩表述建议

- 把点估计和置信区间放在一起，例如“Recall@5 为 90%，95% Wilson CI 为……”。
- K=10 与 K=5 命中率相同，只能说 K=10 在当前离线样本上被支配；部署 K=5 后仍要做线上前后对照。
- 延迟检验在每组 n=4 时只属于探索性结果。可以展示效应量和精确 p 值，但应主动说明下一轮需要扩大样本。
- 8/8 成功不能表述为系统可靠性已达到 100%，应同时展示 Wilson 下界。
